# 교통대 충주 가이드

한국교통대학교 충주캠퍼스의 맛집·숨은장소·학교생활 정보를 모은 모바일 웹앱입니다.

[웹앱 열기](https://kth4778.github.io/knut-chungju-guide/)

## 화면

| 탭 | 내용 |
|---|---|
| 홈 | 맛집·숨은장소 발견과 추천 |
| 지도 | 건물별 장소 묶음, 위치 설명, 출처 |
| 학교생활 | 학생증·프린트·통학 등 98개 생활 안내 |
| 둘러보기 | 실제 장소 사진 탐색 |
| 마이 | 찜·최근 본 곳·거리 기준 |

## 데이터

- 수업 추천 500건을 정규화한 장소 321개를 보존합니다.
- 86곳의 메뉴 1,466개: 네이버 등록 메뉴 1,383개, 휴대폰 배민에서 확인한 메뉴 83개.
- 메뉴 가격은 출처별로 구분하며, 개인 할인가와 배달비는 포함하지 않습니다.
- 메뉴 자료 확인일은 2026-10-24입니다. 배민 메뉴는 확인한 화면 범위의 일부입니다.
- 사진 검수 후 1,048개 메뉴에 사진을 연결했습니다. 고유 메뉴 사진 파일은 1,011개입니다.
- 메뉴 JSON은 가게를 열 때 불러오며 사진은 지연 로딩합니다.
- 미확정 위치 7건과 학식 사진 2곳은 확인 중입니다. 건물 위치와 원본 제보 핀은 실제 출입구/경로의 현장 검증을 뜻하지 않습니다.
- 학교 사진에는 공식 시설 안내 및 2025-04-14 게시된 도서관 외관 사진을 사용하고 게시일과 촬영일을 구별합니다.

네이버·배민·학교 사진의 출처는 화면과 JSON에 표시합니다. 해당 사진의 권리는 원 권리자에게 있으며 별도의 재사용 허락/배포 라이선스를 확보한 것은 아닙니다.

## 개인정보

찜·최근 본 곳·최근 검색은 브라우저에 저장합니다. 현재 위치는 거리 계산에 사용합니다.

## 실행과 배포

빌드가 필요 없는 정적 웹앱입니다.

```bash
python3 -m http.server 5178
```

GitHub Pages는 `gh-pages` 브랜치의 루트(`/`)를 배포합니다.
지도 API의 허용 출처는 `localhost:5178`과 `kth4778.github.io`입니다.
