# 교통대 충주 가이드

한국교통대학교 충주캠퍼스 학생들이 직접 추천한 맛집·숨은장소·생활꿀팁 321곳을 모은 모바일 웹입니다.

- 바로 보기: https://kth4778.github.io/knut-chungju-guide/
- 「도메인 특화 AI 데이터 스토리텔링」 수업에서 모은 추천 500건을 정규화한 데이터로 만들었습니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| 홈 | 분류별 주제 칸, 교내 건물, 추천 랭킹, 충주역·터미널 오가는 법, 가까운 곳 |
| 지도 | 네이버 지도에 장소 249곳. 같은 위치는 하나로 묶어 보여줌 |
| 뭐 먹지 | 맛집 96곳 중 한 곳 뽑기 (만 원 이하 · 1km 이내 · 사진 있음) |
| 도장깨기 | 학식·프린트·999번 버스 등 캠퍼스 생활 퀘스트 12개 |
| 마이 | 찜 · 최근 본 곳 · 도장 · 거리 기준 위치 |

## 개인정보

- 찜·최근 본 곳·도장·최근 검색어는 이 브라우저에만 저장됩니다.
- 현재 위치는 거리를 계산할 때만 쓰고 저장하거나 서버로 보내지 않습니다.

## 직접 실행

빌드 과정 없이 정적 파일만 있습니다.

```bash
python3 -m http.server 5178
```

지도는 네이버 지도 API에 등록한 주소(localhost:5178 · kth4778.github.io)에서만 보입니다.
